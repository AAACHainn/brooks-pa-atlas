你正在实现一个名为 Brooks PA Atlas 的本地 Web App。

目标：
把 Brooks Encyclopedia of Chart Patterns 的本地图表图片库做成一个价格行为学习系统。

第一版核心定位：

Brooks PA Atlas 第一版面向“大批量本地图表图库”。用户通过浏览器上传图片，应用把图片保存到本地图库目录，数据库只保存路径和元数据；用户用可自由维护的百科式索引树组织图片；OCR 通过后台并发队列处理，导入后图片可先浏览，OCR 完成后再补充搜索文本。

核心功能：

1. 支持批量导入图片，单次可处理 1000 张以上图片。
2. 批量导入采用分批上传和导入任务机制，避免单次请求过大或页面长时间卡住。
3. 上传后的图片复制到应用本地图库目录，例如 `data/library/images`；数据库只保存文件路径、原始文件名、文件大小、类型、图片尺寸、hash、导入批次等元数据，不保存图片 blob。
4. 导入时生成 `ImportBatch` 和 `ImportItem`，记录总数、成功数、失败数、重复数、OCR 进度、错误信息和重试状态。
5. 索引模型为用户可维护的无限层级树，不固定 Level1~Level5。
6. 用户可以创建任意深度的索引节点，图片默认挂到一个主要索引节点上。
7. 导入映射采用“分组批量指定”：上传后按上传目录、文件名前缀等方式分组，用户为每组填写或选择索引路径。
8. 重复图片通过 hash 检测，默认跳过重复文件，避免图库膨胀。
9. OCR 不阻塞导入完成。图片先入库并可浏览，后台 worker pool 并发执行 OCR，写入 `ocrText`、`ocrStatus`、`ocrError`、`ocrUpdatedAt`。
10. OCR 并发数提供本地默认值，并允许通过设置扩展，避免大量图片导入时占满机器。
11. 支持百科索引树浏览、按索引查看图片、关键字搜索图片。
12. 搜索覆盖标题、原始文件名、备注、OCR 文本和索引路径；OCR 未完成的图片仍可通过文件名和索引搜索。
13. 图片详情支持查看大图、索引路径、OCR 状态、OCR 文本、错误信息、hash、尺寸、备注，并可编辑标题、备注和索引归类。
14. OCR 失败的图片支持重试。

主要数据模型：

1. `ChartImage`：图片主表，保存应用图库路径、原始文件名、mime type、尺寸、hash、标题、备注、OCR 文本、OCR 状态、所属索引节点、导入批次、创建/更新时间。
2. `IndexNode`：无限层级索引节点，保存名称、父节点、排序、深度和完整路径。
3. `ImportBatch`：一次批量导入任务，保存状态、总数、成功数、失败数、重复数、OCR 完成数、OCR 失败数、开始/结束时间。
4. `ImportItem`：单张图片在导入批次中的处理记录，保存原始文件名、保存路径、映射索引、状态和错误。
5. `AppSetting`：保存图库根目录、OCR 并发数、默认导入行为等本地设置。

第一版界面：

1. 首页就是 Atlas 工作台，不做营销落地页。
2. 左侧为无限层级索引树和索引创建入口。
3. 中间为搜索、批量导入、导入分组映射、图片网格和图库状态统计。
4. 右侧为图片详情、OCR 状态、失败重试、批次状态和图片元数据。

技术栈：

Next.js App Router + TypeScript + Tailwind CSS + Prisma + SQLite。
图片只存路径，不存数据库 blob。

第一版不做：

1. 不做登录。
2. 不做云同步。
3. 不做 AI 分类或 AI 分析。
4. 不直接引用用户硬盘原始路径；浏览器上传后保存到应用本地图库目录。
5. 不做多标签体系；一张图片默认归属一个主要索引节点，多标签作为后续扩展。
