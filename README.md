# Brooks PA Atlas

Brooks PA Atlas 是一个本地 Web App，用来管理 Brooks 价格行为图表图片库。它支持批量导入本地图片、将 PDF 资料逐页转换为图片、按无限层级索引整理图片、查看和编辑图片信息、使用资料 RAG 知识库、AI 阅读伴侣与 AI 精校 OCR、制作遮罩选择题试卷，并在后台异步执行 OCR。

## 环境要求

- Node.js：建议使用 `22.13.0` 或更新版本；PDF 导入依赖 `pdfjs-dist`，需要较新的 Node.js 运行时。
- npm：随 Node.js 安装。
- SQLite：项目通过 Prisma + better-sqlite3 使用本地 SQLite 数据库。
- OCR：导入图片后会触发后台 OCR 队列，部署机器需要全局安装 `tesseract`，否则 OCR 会失败，并可能影响导入后的处理体验。

使用 Docker Compose 运行时，只需要 Docker Engine 和 Docker Compose v2。镜像已经包含 Node.js、Tesseract、简体中文和英文 OCR 语言包，不需要在宿主机另外安装这些依赖。

## 使用 Docker Compose 启动

在项目根目录执行：

```bash
docker compose up -d --build
```

启动完成后访问 `http://localhost:3000`。如果当前用户无权访问 Docker socket，请给命令加上 `sudo`。

常用管理命令：

```bash
docker compose ps
docker compose logs -f atlas
docker compose restart atlas
docker compose down
```

`docker compose down` 只停止并移除容器和 Compose 网络，不会删除命名卷。应用数据保存在名为 `brooks-pa-atlas-data` 的 Docker volume 中：

- SQLite 数据库：`/app/data/dev.db`
- 图片图库：`/app/data/library/images`

重新构建或替换容器时会继续使用同一个数据卷。不要使用会删除 volume 的 Compose 参数，否则数据库和图库数据可能丢失。

Compose 固定把宿主机 `3000` 端口映射到容器 `3000` 端口，以保证访问地址始终为 `http://localhost:3000`。

容器启动时会自动初始化空数据库，并对已有数据库执行全部增量 migrations。更新源码后的常规升级命令同样是 `docker compose up -d --build`。

## 本地运行时安装 OCR 依赖（Tesseract）

Brooks PA Atlas 默认调用命令行里的 `tesseract`：

```text
tesseract <imagePath> stdout -l chi_sim+eng
```

因此部署完成后必须能在终端直接运行：

```powershell
tesseract --version
```

Windows 推荐安装 UB Mannheim 提供的 Tesseract OCR 构建。优先使用 `winget`：

```powershell
winget install --id UB-Mannheim.TesseractOCR --exact
```

如果本机没有 `winget`，可从 UB Mannheim / Tesseract 的 Windows release 下载 `tesseract-ocr-w64-setup-*.exe` 安装器。安装目录建议保持默认：

```text
C:\Program Files\Tesseract-OCR
```

安装后请确认该目录已加入 PATH。PowerShell 可以这样添加到当前用户 PATH：

```powershell
$tessDir = "C:\Program Files\Tesseract-OCR"
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
if (($userPath -split ";") -notcontains $tessDir) {
  [Environment]::SetEnvironmentVariable("Path", ($userPath.TrimEnd(";") + ";" + $tessDir), "User")
}
```

修改 PATH 后，需要重新打开终端；如果开发服务已经在运行，也需要重启 `npm run dev`，否则服务进程可能仍然读不到新的 `tesseract` 命令。

Linux/macOS 常见安装方式：

```bash
sudo apt update
sudo apt install tesseract-ocr
```

默认 OCR 语言是简体中文加英文混合识别，因此还需要安装简体中文 language data。例如 Ubuntu/Debian 的简体中文语言包通常是：

```bash
sudo apt install tesseract-ocr-chi-sim
```

## 初始化数据库

第一次运行，或本地没有 `dev.db` 时，执行：

```powershell
npm run db:init
```

该命令会分别初始化 `dev.db` 与独立的 `knowledge.db`，并继续应用两套增量 migrations。已有数据库升级时也可以执行 `npm run db:migrate`。知识库数据库默认是 `file:./knowledge.db`，可用 `BROOKS_KNOWLEDGE_DATABASE_URL` 覆盖；字幕根目录默认是 `data/library/knowledge`，可用 `BROOKS_KNOWLEDGE_ROOT` 覆盖。两者必须放在本地 SSD 或 Docker volume，不要放到网络文件系统。

如果修改过 Prisma schema，需要重新生成 Prisma Client：

```powershell
npm run prisma:generate
```

## 手机访问本机图库

手机访问时仍然使用电脑上的本地数据库和本地图片文件，不需要把图片上传到云端，也不要改动图库目录。

1. 在电脑上启动局域网服务：

```powershell
npm run dev:lan
```

如果服务已经在运行，修改访问方式或配置后请先停止旧服务，再重新执行上面的命令。

生产构建后也可以使用：

```powershell
npm run start:lan
```

2. 让手机和电脑连接到同一个局域网。
3. 在手机浏览器打开电脑的局域网地址，例如：

```text
http://192.168.1.23:3000
```

不要在手机上打开 `http://localhost:3000`。手机里的 `localhost` 指的是手机自己，不是运行 Brooks PA Atlas 的电脑。

如果页面能打开但索引和图片都是空的，先在手机浏览器访问：

```text
http://电脑局域网IP:3000/api/atlas
```

确认返回内容里的 `stats.imageCount` 是否大于 `0`。本机已有数据时，这个接口应该和电脑浏览器访问同一地址返回一致。

开发服务默认允许任意 IPv4 地址访问 Next.js dev resource，便于在不同局域网地址之间切换。如果仍然遇到浏览器控制台提示某个非 IPv4 主机名被 Next.js 阻止，可以在启动前手动追加允许的地址：

```powershell
$env:BROOKS_ALLOWED_DEV_ORIGINS="192.168.1.23"
npm run dev:lan
```

## 基本使用

### 1. 选择模式

页面左侧可以在“浏览”、“管理”和“考试”之间切换。

- 浏览模式：只查看图片和索引，适合学习和检索。
- 管理模式：可以导入图片、创建索引、编辑图片信息、删除图片和管理索引。
- 考试模式：可以用图库里的图片制作试卷、发布考试、作答并复盘历史记录。

### 2. 创建索引

在管理模式下，左侧输入索引名称后点击创建按钮。

- 未选中索引时，会创建根索引。
- 选中某个索引时，会在该索引下创建子索引。
- 索引支持多层级。

### 3. 导入图片

在管理模式下，点击顶部的 `导入图库` 按钮，然后选择：

- `选择图片`：一次选择多张图片。
- `选择文件夹`：选择整个文件夹，系统会识别其中的图片文件。
- `导入 PDF`：系统会读取 PDF 内置书签目录，将每一页转换为图片，并按目录层级挂到索引树上；导入时会显示页级进度。

按钮旁的提示图标会说明三种方式都导入图库。选择图片、文件夹或 PDF 后，“导入后 OCR”开关才会出现在对应的待导入区域，每次新选择默认关闭；设置好后点击“开始导入”。PDF 选择后会先展示文件名和目标索引路径，确认开始导入后才上传并显示页级进度。

导入前可以在表格里为每张图片指定所属索引。表格支持分页，但点击导入时会提交全部已选择图片，不只提交当前页。

PDF 导入规则：

- 未选中索引时，会在根节点创建以 PDF 文件名命名的容器索引。
- 选中某个索引时，会在该索引子树下创建 PDF 文件名容器索引。
- PDF 有内置书签目录时，页图片会挂到对应书签章节下；没有书签时，所有页图片挂到 PDF 容器索引下。
- PDF 页面默认以 1.8 倍渲染，压缩为 JPEG，最长边限制为 1920px，初始质量为 84，并默认把单页图片控制在 500KB 以内；转换后的图片会进入同一套图库、SHA-256 去重、导入批次、OCR、备份和撤销流程。
- PDF 页面导入默认使用 2 路并发，避免大文档长时间卡在单个同步请求里。

PDF 转图片参数可以用环境变量调整：

```powershell
$env:BROOKS_PDF_RENDER_SCALE="1.8"
$env:BROOKS_PDF_MAX_IMAGE_EDGE="1920"
$env:BROOKS_PDF_JPEG_QUALITY="84"
$env:BROOKS_PDF_MAX_IMAGE_BYTES="512000"
$env:BROOKS_PDF_IMPORT_CONCURRENCY="2"
```

支持的常见图片格式包括：

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`
- `.gif`
- `.bmp`
- `.tif`
- `.tiff`

### 4. 索引导航器

搜索栏下方提供可折叠的“索引导航器”，浏览和管理模式均可使用，考试模式自动隐藏。导航器初始为空，不从 Excel、标签或索引名自动生成数据。

- 管理模式可通过齿轮创建分类和选项、调整排序，并在可展开的树形列表中批量配置节点；勾选或取消父节点会同步作用于全部后代，索引树右键菜单也可编辑单个节点。
- 同一分类内多选按“或”匹配，不同分类之间按“且”匹配。属性只检查节点自身，不从父节点继承；命中节点后会包含该节点全部后代图片。
- 目录关键词、图片关键词、标签和具体目录会继续与导航条件取交集。点击匹配目录会定位左侧树，也可返回全部匹配目录的图片合集。

### 5. 备份和恢复

在管理模式下，可以使用顶部按钮进行数据备份和恢复。

- `备份管理`：先在服务器上生成 v7 zip，再从备份列表单独下载。列表会显示生成时间、文件大小、图片数和备份范围，也可以删除不再需要的备份。备份包含全部树状索引、导航分类/选项/节点关联、图片文件、标题、备注、标签、文字标注、OCR 状态、完整考试数据，以及资料知识文档、单节点绑定、历史版本、源文件、定位信息、片段、关键词和向量 BLOB；不会直接复制运行中的 SQLite 文件。
- `恢复`：导入备份 zip。恢复采用合并覆盖模式，相同 SHA-256 hash 的图片会覆盖元数据、标签和所属索引，不会重复生成一份，也不会删除当前系统中备份外的数据；导航关联通过备份内标识重建，试卷题目按图片 hash 映射。恢复 v1–v4 旧备份时保留目标系统现有导航数据。

AI 端点、技能提示词、API Key 和阅读伴侣会话属于当前实例的本地数据，不进入备份 zip，恢复备份也不会修改它们。资料知识库内容会进入备份；导入/维护任务记录和 FTS5 派生索引不会进入备份，恢复时会重建全文索引。阅读伴侣会话保存在 SQLite 中，服务重启后仍会保留，但移动实例时需要保留原数据库。

备份生成、下载和恢复都使用磁盘文件与流式 I/O，不会把完整 zip 放入 Node.js 或浏览器内存；恢复时图片也会逐张流式校验和写入。服务器仍需预留足够磁盘空间：生成备份时需要容纳备份 zip，恢复上传时需要临时容纳上传的 zip。

备份包只保存跨平台相对路径，不保存 Windows 或 Linux 的绝对路径。因此可以在 Windows 开发环境导出备份，再在 Linux 部署环境恢复。恢复时图片会写入当前系统的 `BROOKS_LIBRARY_ROOT`，未设置时写入默认图库目录。

如果备份时数据库记录指向的图片文件已经丢失，系统会返回错误并停止导出，避免生成不完整备份。

### 6. 浏览图片

导入完成后，图片会出现在中间的图片网格中。

- 点击左侧索引可以筛选图片。
- 顶部搜索框可以搜索标题、OCR 文本、备注、索引路径和标签；旁边的标签筛选菜单支持多选，多个标签按交集筛选。
- 浏览模式标题栏和图片卡片会显示标签；点击标签可以切换对应的精确标签筛选。
- 图片网格使用服务端分页，支持每页 25、50、100 或 200 张，并保持全库自然数字排序。
- 浏览模式下可以打开大图查看器，并使用左右箭头或键盘方向键切换图片。

### 7. 编辑图片信息

在管理模式下，点击图片后可在右侧详情面板编辑：

- 标题
- 所属索引
- 备注
- 标签

编辑后点击“保存”生效。

#### AI 阅读伴侣与 OCR 精校

项目已提供供后续功能复用的服务端 AI 工具调用基础设施，包括图片资料和索引查询两个正式只读工具。当前界面没有入口，现有 AI 功能不会自动调用；不增加公开执行接口、不修改数据库。开发接入方式见 [AI 工具架构说明](docs/AI_TOOL_ARCHITECTURE.md)。

管理模式顶部的“设置”把“大模型”和“Embedding”分成两个独立页签。两类端点分别配置供应商、API Base URL、API Key、模型列表和启用项，因此可以让 DeepSeek 等大模型供应商与 OpenAI-compatible Embedding 供应商完全独立。高级模式可分别填写完整的 Chat Completions、Embeddings 与 Models URL。API Key 为空时不会发送 `Authorization` 请求头，适合不要求鉴权的本地模型服务。旧 `ai.config.v1` / `ai.config.v2` / `ai.config.v3` 会在读取时自动迁移到 v4，不丢失已有端点和密钥。

“技能”页提供“AI 精校 OCR”“AI 阅读伴侣”和“字幕知识整理”：三者都可以编辑提示词，并分别选择是否覆盖启用端点的默认模型。字幕整理还可以指定更便宜的失败重试模型和单窗口输出 Token 配置上限；字幕 AI 导入固定关闭 thinking/reasoning，不能由界面重新开启。OCR 与伴读模型必须支持图片输入；字幕整理只发送文本。

伴读输入框上方可选择“快速回答 / 深度思考”，默认快速回答。快速回答适合当前图片的局部问题，优先当前图片关联资料，最多使用 8 个知识片段，一次回答模型调用完成。深度思考适合整章总结、多课程比较和书籍与字幕综合；两种模式共用伴读技能的模型和提示词。发送期间模式锁定，点击“停止”或关闭伴读窗口会取消请求，未完成的回答不保存为成功答案。

8 个片段是上限，资料不足时不会凑满：检索会过滤低相关的向量结果，全库搜索只依据问题中的具体主题。“翻译当前图片”等局部请求在图片没有关联资料时，不会用图片 OCR 或标题搜索其他课程。未匹配到资料会显示“未找到相关知识库资料”，仍可依据图片回答。“参考资料”列出本次提供给 AI 的片段，回答实际采用的依据以正文引用为准；已有历史消息保留当时的资料快照。

在“设置 → 技能 → AI 阅读伴侣 → 深度思考预算”中配置：

| 配置 | 默认值 | 作用 |
|---|---:|---|
| 单次上下文输入 Token 预算 | 16,000 | 每次调用的提示词、当前问题、历史、图片与证据 |
| 整个问题累计输入 Token 预算 | 100,000 | 拆解、排序、分批阅读和综合的累计输入，失败尝试也计入 |
| 最终回答输出 Token 上限 | 4,096 | 传给上游模型的最终回答输出限制 |

三项必须是正整数，累计输入预算不能小于单次预算。旧配置自动补齐默认值，无需数据库迁移。每次提问固定使用启动时已保存的预算；发送期间修改设置只影响下一个问题。输入 Token 使用保守估算并预留 10% 余量，图片额外计入估算；这不是供应商的实际账单 Token，也不能提高模型自身的上下文容量。请根据所选模型的输入与输出限制配置预算。

深度模式显示拆解、检索、排序、阅读、综合阶段：最多拆解 6 个子问题，批量生成问题向量，再串行查询全文、关键词和向量通道（每个子问题每通道最多 50 个候选）。去重后按资料和子问题保证覆盖，对最多 60 个候选摘要二次排序。整章总结按章节标题路径分页读取有序正文，排序不会剔除章节内容；无法唯一定位课程或章节时会请求澄清。证据超过单次输入预算时先分批阅读，再综合回答；必要时减少旧历史和旧参考图，当前问题不会被静默截断。

最多 10 次聊天模型调用、6 个阅读批次为固定限制，并始终为最终综合预留调用与输入预算。达到限制时停止扩展阅读，显示已读取及未覆盖范围；“证据覆盖”中可查看各资料的片段数、调用数、估算输入 Token 和降级提示。排序失败保留融合排序，向量不可用时降级为全文与关键词；没有可用知识证据时会说明资料不足。原思考面板继续显示供应商实际返回的可见思考内容，阶段进度不会冒充模型推理。

#### 资料知识库

管理模式顶部的“资料知识库”或索引节点右键“导入/关联资料”可导入字幕和通用文本。`.srt/.vtt/.ass` 固定为字幕；`.txt` 可逐文件选择 `SUBTITLE/BOOK/ARTICLE/NOTE/OTHER`，`.md/.markdown` 可选择除字幕外的资料类型，并支持批量设置。单文件最多 10 MiB，单批最多 200 个文件且总计不超过 100 MiB。每个文件都必须确认资料类型和索引节点映射；系统仍会按完整课号词和描述名称提供保守的节点自动匹配。

每份资料只绑定一个索引节点，每个节点最多绑定一份资料。同节点再次导入相同类型会显示目标资料并创建新版本；不同类型返回冲突。资料类型创建后不能随版本改变。解除绑定只移入“未关联”分组并停止参与检索，不删除文档、版本或源文件；绑定还可以控制是否应用到后代索引。

导入时默认选择“快速导入（推荐）”：字幕由程序完成重复/滚动去重、规范化和确定性分段；普通 TXT 按段落、Markdown 按标题层级和段落确定性切片，保留标题路径与源文件行号。随后直接生成 Embedding 与 FTS，聊天模型 Token 消耗为零。“AI 深度整理”仅在整个批次都是字幕时可选；混合批次和通用资料强制使用快速导入。

导入进度会分别显示整批文件状态、当前文件的程序分段或 AI 窗口进度，以及 Embedding 批次进度。AI 模式显示累计输入/输出 Token、当前窗口和重试次数；失败时可展开查看该窗口输入与截断后的模型输出。每次请求前会把输出上限限制为“配置上限、3000、预估输入 Token 两倍”三者的最小值；供应商返回 `finish_reason=length`、仍返回推理内容/Token，或最终输出仍超过实际输入 Token 两倍时，整份文档立即失败，不重试该窗口、不回退到程序分段。Embedding 每批最多提交 20 个知识片段；失败条目可以在修复配置或服务问题后单独重试。

“人工预览后再入库”每次打开默认关闭且不记忆。关闭时，处理结果通过程序校验后自动激活；打开时，任务停在等待审核，只能整份预览、批准或拒绝。AI 模式允许程序补齐少量遗漏 cue，严重遗漏、重叠、倒序或无效 JSON 才完整重试一次。相同字幕、处理模式、规则、提示词和模型会复用已有片段；当前 Embedding profile 匹配时也复用向量。重新导入同一节点仍会建立新版本，只有新版本的片段、FTS 和向量全部就绪后才原子切换。知识文档页按直属父节点左右分栏管理并支持搜索；版本行中的片段数可点击查看原字幕、知识文本、时间范围、主题和关键词，由字幕整理模型决定边界的版本会标记“AI 分段”。

“重建全文索引”和“重建全部向量”收在默认折叠的“高级维护工具”中，按钮旁的说明图标可查看用途。两项操作都会先确认；向量重建会显示当前 Embedding 端点、模型、片段数、向量覆盖情况和费用提醒，达到 1000 个片段时还必须输入确认短语。

资料数据保存在独立 `knowledge.db`，源文件保存在 `data/library/knowledge/sources/`；PPT 图片仍只属于图库，不复制进知识库。伴读仅检索已启用且绑定有效的资料，当前范围包含当前节点及从父节点到根节点所有启用“应用到后代”的资料。快速模式最多提供 8 个 `[K1]` 等引用，深度模式按 Token 预算装载更多证据。来源展示资料标题、版本、课号、字幕时间码或 TXT/Markdown 标题路径与行号，并可展开原始片段。阅读笔记和最终答案沿用同一组原始编号；不存在的编号标记为“未验证引用”。回答保存当次引用正文与位置快照，后来换版本或删除资料也不影响历史追溯。书籍全文需先通过 TXT/Markdown 等现有格式进入知识库，本次没有增加 PDF/EPUB 全文解析。

为适配 2 核 2GB 实例，批量 OCR、PDF 导入、缩略图补齐、资料知识导入、全量向量重建和伴读深度思考使用同一个进程级重任务租约；已有重任务运行时，新任务会提示稍后再试。深度请求停止、断开或失败时释放租约。

图片已有 OCR 文本时，点击右侧 OCR 卡片里的“AI 精校”，应用会把当前图片和文本发送到启用的外部端点。返回结果只会替换页面中的未保存草稿，不会自动写入数据库；确认内容后仍需点击“保存 OCR 文本”。

浏览模式中央大图支持右键“AI 伴读”。伴读窗口默认停靠在右侧，可以拖动、从四边或四角调整宽高、收起和关闭，并会记住位置、尺寸与收起状态；收起后再次展开会恢复之前的消息阅读位置。AI 回复会按 Markdown 渲染标题、列表、引用、表格、链接和代码块。兼容端点如果返回 `reasoning_content`、`reasoning`、`thinking` 或 reasoning 数组，窗口会实时显示可折叠的思考过程和思考耗时；端点未返回时只显示计时并明确说明没有可展示内容，不会伪造模型内部推理。窗口打开后会自动跟随当前大图；AI 可以读取图片、标题、标签、备注、OCR、文字标注、索引路径、节点导航属性和技术元数据。会话支持新建、切换、重命名、清空和删除，消息通过 SQLite 持久保存。快速模式每次接收最近 40 条、最多约 60,000 字的会话上下文。普通问题默认只附带当前原图及其最新资料快照；跨索引或跨主题切图后，直接在原会话提问即可。明确要求比较或回看历史图片时，才附带当前图片和最多 3 张近期不同参考图，并区分当前图与历史图；深度模式会按技能预算进一步缩减旧上下文，并压缩当前图片的长 OCR、备注和标注摘要。更早历史仍可在窗口中查看。

安全说明：API Key 明文保存在当前实例的 SQLite 数据库中，但不会回传到浏览器、不会写入日志，也不会进入应用备份 zip。AI 精校会发送图片和 OCR；AI 伴读会发送近期会话、参考图片及其标签、备注、OCR、标注、索引属性和技术元数据。请只配置可信端点，并确认其隐私和数据保留政策。当前应用没有登录系统，只应部署在可信本机或可信局域网中。

图片卡片左上角的复选框可以跨页选择多张图片。选中后，批量标签工具栏可以统一添加或移除标签；切换搜索、索引、标签筛选或页面模式时会清空选择，避免误改隐藏图片。

### 8. 考试模式

考试模式用于把图库图片制作成遮罩选择题，并记录每次作答结果。

#### 创建和编辑试卷

进入考试模式后，可以通过试卷区域的 `+` 按钮创建新试卷，也可以从下拉菜单导入试卷。

- 新建试卷会先进入草稿状态。
- 草稿试卷可以从现有图库分页搜索并添加图片，每张图片会生成一道题。
- 题目支持单选题和多选题。
- 每道题可以设置题干、选项、正确答案、解析和图片遮罩。
- 遮罩支持多个矩形，只保存相对坐标，不会生成新图片。

题目保存后，如果内容满足发布要求，会进入已就绪状态。发布要求包括：

- 题干不能为空。
- 至少有 2 个有效选项。
- 单选题只能有 1 个正确答案。
- 多选题至少需要 2 个正确答案。
- 至少绘制 1 个遮罩矩形。

已就绪题目再次修改并保存时，如果内容有变化，页面会提示修改成功。

#### 发布和作答

试卷发布前，所有题目都必须处于已就绪状态。发布后试卷内容会锁定，避免历史考试记录和题目内容不一致。

开始考试后：

- 后端会随机题目顺序。
- 选项顺序保持试卷内的原始顺序。
- 作答页使用单题视图，可以用按钮或键盘方向键切换上一题/下一题。
- 图片支持缩放和拖拽查看局部。
- 看图窗口底部把手可以调整高度，最高可调整到 2000px。
- 切换题目时会保留当前缩放比例；该比例只记录在前端，不写入数据库。

提交答案后，系统会保存考试记录，包括用时、正确数、总题数、正确率和每题答案。结果页支持查看解析、显示或隐藏遮罩，以及只看错题。

#### 拷贝、导出和导入试卷

试卷列表支持右键菜单：

- 拷贝试卷：把现有试卷复制成新的可编辑草稿，只复制题目内容，不复制考试记录。
- 导出试卷：已发布试卷可以导出为轻量 JSON 文件；导出内容不包含图片文件，只包含图片索引信息和题目数据。

导入试卷在原 `+` 添加试卷入口的下拉菜单中。导入文件不会携带图片文件，系统会按图片 hash 在当前图库里重新匹配题目图片；因此导入前需要先确保相关图片已经存在于当前图库。

### 9. OCR 和重试

图片导入后会进入后台 OCR 队列。OCR 不会阻塞图片入库和浏览。

如果某张图片 OCR 失败，可以在右侧详情面板点击重试按钮。请先确认部署机器已经全局安装 Tesseract，并且运行服务的终端可以直接执行 `tesseract --version`。默认 OCR 命令是：

```text
tesseract
```

Windows PowerShell 可以这样指定其他 OCR 命令：

```powershell
$env:BROOKS_OCR_COMMAND="tesseract"
```

也可以指定 Tesseract 语言组合：

```powershell
$env:BROOKS_OCR_LANG="chi_sim+eng"
```

如果语言包不在 Tesseract 默认安装目录，可以指定 tessdata 目录：

```powershell
$env:BROOKS_TESSDATA_DIR="D:\path\to\tessdata"
```

Linux/macOS shell 可以这样指定：

```bash
export BROOKS_OCR_COMMAND=tesseract
```

也可以指定 Tesseract 语言组合：

```bash
export BROOKS_OCR_LANG=chi_sim+eng
```

如果语言包不在 Tesseract 默认安装目录，可以指定 tessdata 目录：

```bash
export BROOKS_TESSDATA_DIR=/path/to/tessdata
```

如果希望只对本次启动生效，也可以在 Linux/macOS 下这样运行：

```bash
BROOKS_OCR_COMMAND=tesseract BROOKS_OCR_LANG=chi_sim+eng BROOKS_TESSDATA_DIR=/path/to/tessdata npm run dev
```

默认 OCR 调用参数相当于：

```text
tesseract <imagePath> stdout -l chi_sim+eng
```

因此默认会同时识别简体中文和英文。如果需要识别其他语言，需要先安装对应的 Tesseract language data，并通过 `BROOKS_OCR_LANG` 调整语言组合。

### 10. 删除和撤销

管理模式支持以下高风险操作：

- 删除单张图片：需要弹窗确认。
- 撤销某个导入批次：需要弹窗确认。
- 删除索引：只有该索引及其子索引下没有图片时才能删除。
- 清空某个索引下的图片：需要在确认弹窗中输入 `确认删除`。

这些操作会影响本地数据库和图库文件，请谨慎执行。

## 本地数据位置

默认情况下：

- 数据库文件：`dev.db`
- 图片图库目录：`data/library/images`

Windows PowerShell 可以通过环境变量覆盖图库根目录：

```powershell
$env:BROOKS_LIBRARY_ROOT="D:\your-library-root"
```

Linux/macOS shell 可以这样设置：

```bash
export BROOKS_LIBRARY_ROOT=/home/you/brooks-library
```

数据库只保存图片路径和元数据，不保存图片 blob。

## 常见问题

### 文件夹导入后没有图片

请确认文件夹中包含支持的图片格式。部分系统会让浏览器提供空 MIME 类型，本项目会同时按扩展名识别图片。

### OCR 一直失败

请先确认本机可以直接运行 Tesseract。

Windows PowerShell：

```powershell
tesseract --version
```

Linux/macOS shell：

```bash
tesseract --version
```

如果命令不存在，需要先安装 Tesseract OCR，或者设置 `BROOKS_OCR_COMMAND` 指向可用命令。安装或修改 PATH 后，请重启终端和开发服务。

如果错误提示缺少 `chi_sim.traineddata`，请安装简体中文语言包，或临时把 `BROOKS_OCR_LANG` 改成当前机器已安装的语言组合。

常见 Linux 安装方式：

```bash
sudo apt update
sudo apt install tesseract-ocr
```

默认语言组合包含简体中文，因此需要安装对应语言数据。例如 Ubuntu/Debian 的简体中文语言包通常是：

```bash
sudo apt install tesseract-ocr-chi-sim
```

### 页面没有更新

可以点击左侧刷新按钮，或重新打开 `http://localhost:3000`。

### 本地数据可以直接删除吗

不建议直接删除运行数据。特别是 `data/library/` 和 `dev.db` 之间有关联，手动删除可能导致数据库记录和图片文件不一致。

### 全局 AI 机器人

网页右侧的机器人按钮可拖动，点击打开独立聊天窗口。窗口支持拖动、调整大小、收起、关闭及持久化多会话；收起继续运行，停止或关闭取消任务。

管理模式 → 设置 → 技能 → AI 机器人，可以关闭机器人、覆盖模型或编辑提示词。默认继承启用端点的模型，需要支持 Chat Completions 工具调用；不会在启动时自动探测或调用模型。

展开机器人卡片中的“高级运行限制”，可调整每个问题的模型请求次数、工具调用次数、单次与累计输入 Token、单次输出 Token 和任务总时长。默认仍为 6 次模型、12 次工具、16000/100000 输入 Token、4096 输出 Token、300 秒；可快捷设为 12/24 次调用。提高次数不会改变输入预算，也不能提高模型自身容量。新限制从下一次发送生效，其他 AI 功能沿用原配置。

接近运行上限时，机器人优先根据已成功读取的资料生成答案，明确尚未解决的内容；达到限制时展示具体原因、实际调用和成功读取统计。你可以缩小范围继续提问，或调整设置后点击“重试此问题”。重试使用原问题与原参考对象，按当前设置重新执行，不会自动续跑。索引查询返回过滤后总数，图片资料可按字段分页读取，以减少不必要的正文和重复查询。

首版开放两个只读工具：查询索引、读取当前或明确指定图片保存的文字资料。不发送原图；全面内容检索、图库整理和日志诊断将在后续加入。机器人与阅读伴侣的会话和流程独立，历史不进入备份 zip。

新增数据库 migration `20261006100000_ai_robot`。已有实例先备份，再执行 `npm run db:migrate`、`npm run prisma:generate` 并重启服务；仅更新源码或启动开发服务不会应用 migration。缺少会话表时机器人会明确提示升级，升级完成后点击“重新加载会话”或重新打开窗口。机器人专项测试：`npm run test:ai-robot`（也包含在 `test:ai` 中）。

切换大模型端点后，技能中保留的旧模型覆盖若只在其他端点的模型列表中出现，本次会继承当前端点的默认模型；设置的技能卡显示实际调用模型和提示。旧覆盖不会删除，切回原端点仍可使用。需要通过新端点调用同名模型时，先将其添加到该端点的模型列表；未被任何端点列出的手动模型仍可作为覆盖使用。


### 机器人聊天模式

打开 AI 机器人，在窗口底部点击“＋”选择：

- **普通模式**：沿用索引与图片文字查询。
- **阅读伴侣**：仅浏览模式可用，跟随当前图片，保留快速/深度思考、知识引用等能力；共用原伴侣历史。原伴侣窗口和右键入口继续保留，供对照使用。
- **任务模式**：输入只读分析目标，先查看步骤和资料范围，再点击“开始执行”。可输入反馈重新规划；执行时显示批次进度和可展开的检查点/证据。暂停立即中断当前批次，继续从最近检查点重做；关闭窗口或刷新页面仍在后台执行。服务重启后需要手动继续。

任务模型和总预算可在“管理设置 → 技能 → 任务模式”独立调整。累计消耗不会因暂停清零；源资料发生变化时需要重新规划。

升级现有安装须运行 `npm run db:migrate`、`npm run prisma:generate`，然后重新构建并重启。请先备份现有数据库；完整步骤见 `docs/DEPLOYMENT_PITFALLS.md`。
